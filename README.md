
# Домашнє завдання 9 — Варіант 11

## Тема
Доведення від ШІ, перевірка кодом і GitHub.

## Мета роботи
Перевірити математичне твердження за допомогою програми Python, виконати критичний аналіз геометричного доведення, створеного штучним інтелектом, та навчитися працювати з GitHub.

## Варіант 11

### Задача 1. Перевірка кодом

Потрібно перевірити, чи ділиться вираз

`4**n + 6*n - 1`

на 9 для натуральних чисел від 1 до 100.

Для перевірки використовується файл `check.py`.

### Задача 2. Геометричне доведення

Медіана прямокутного трикутника, проведена до гіпотенузи, дорівнює половині гіпотенузи.

Для цієї задачі виконано аналіз доведення, згенерованого ChatGPT.

## Структура репозиторію

- `check.py` — програма для перевірки подільності.
- `README.md` — опис репозиторію.

## Як запустити програму

1. Завантажити файл `check.py`.
2. Відкрити Python або Google Colab.
3. Запустити програму.
4. Переглянути результат перевірки.

## Результат

Програма перевіряє твердження для 100 натуральних чисел.

Відсутність контрприкладів підтверджує правильність твердження лише для перевірених значень, але не є математичним доведенням для всіх натуральних чисел.
